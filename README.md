\# Food Delivery Time Prediction



A machine learning project that predicts food delivery time based on delivery-related features.



\## Project Overview



This project uses machine learning to estimate how long a food delivery will take.



\## Technologies



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Matplotlib

\- Seaborn

\- Flask

\- Jupyter Notebook



\## Project Structure



\- data/ - Dataset files

\- notebooks/ - Exploratory data analysis

\- src/ - Machine learning source code

\- artifacts/ - Trained models
