# Food Delivery Time Prediction

A machine learning project to predict food delivery time using customer, restaurant, order, and delivery-related data.

## Project Goal

The goal is to analyze food delivery data and build a machine learning model that predicts the estimated delivery time.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
- Flask

## Project Structure

- `data/` - Dataset files
- `notebooks/` - Exploratory data analysis
- `src/` - Source code
- `artifacts/` - Saved model files
- `requirements.txt` - Python dependencies

## Dataset

Food Delivery Time Prediction dataset.
